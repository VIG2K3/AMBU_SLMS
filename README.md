Contribution of my part For Shelf Life Managment System such managing products with barcode generation, approval workflows, and email notifications. The system has two interfaces: Admin and User.

Admin Interface (ProductAdmin.py):
  - Approve/Reject products submitted by users
  - Barcode generation and management
  - Email notifications for approvals/rejections
  - Test date reminders scheduling
  - Excel export with embedded barcode images
  - Search and filtering capabilities

User Interface (ProductUser.py):
  - Submit new products for admin approval
  - View product status (Pending/Approved/Rejected)
  - Barcode generation for submitted products
  - Search and filter products
  - Delete pending or rejected products

Batch Registration Form (BatchForm.py):
  - Integrated user interface with clock and logout functionality
  - Wrapper for the Product Manager user interface
